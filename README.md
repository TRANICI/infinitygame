# 尘线 · DUSTLINE

在 Dust2 路线与高低差上重建的单机 5V5 网页 FPS。你与 4 名 AI 队友组成蓝队，对抗 5 名橙队 AI。先赢 5 回合获胜，每回合 120 秒，阵亡后观战队友，下一回合重新出发。

[立即游玩](https://tranici.github.io/infinitygame/) · [源码](https://github.com/TRANICI/infinitygame)

## 开始游戏

直接打开 index.html 或双击「开始游戏.bat」。也可以执行 npm start，访问 http://127.0.0.1:4173。无需安装运行依赖，无需账号或服务器。首次点击「进入战场」启动 WebAudio 音效。

这是本地 AI 对战版本，不包含联网匹配、炸弹模式或购买经济系统。医院、档案翼、解谜、追逐者和旧恐怖效果已从当前源码与发布包移除；旧实现保留在 Git 历史中。

## 武器与操作

| 操作 | 桌面端 | 手机端 |
| --- | --- | --- |
| 移动 / 转向 | WASD / 鼠标 | 左摇杆 / 右侧空白区域滑动 |
| 开火 / 刀击 | 鼠标左键 | 按住「开火」 |
| 瞄准 | 按住鼠标右键 | 点击「瞄准」切换 |
| 换弹 | R | 「换弹」 |
| 跳跃 / 静步 | Space / Shift | 「跳跃」 |
| 切换步枪、手枪、蝴蝶刀 | 1、2、3 | 底部武器栏 |
| 检视蝴蝶刀 | 持刀时按 F | 持刀时点击「检视」 |
| 记分板 | 按住 Tab | 「排行」 |
| 暂停 | Esc | 右上角「Ⅱ」 |

- AR-30：30 发弹匣，90 发备用，自动射击。
- P-12：12 发弹匣，48 发备用，较慢的射速。
- 蝴蝶刀：2.15 米攻击距离，单次伤害 65。两个独立刀柄、金属刀刃、铰链、护手与手套均为程序化 3D 模型。
- 检视依次循环「翻柄开合」「指间旋转」「空中抛接」，有独立动画与金属碰撞音。开火、切枪、阵亡和回合结束会中断检视；可以连续按 F 切换动作。

手机端始终采用横屏布局。竖握时旋转整个游戏，同时反向转换摇杆与视角触点；横握时正常显示，不依赖浏览器的屏幕方向锁定接口。设置中可调整音效音量与视角灵敏度，保存在本机。电脑端失去鼠标锁定、窗口失焦或切换标签页时暂停。

## 战斗与地图

双方各 5 人。AI 沿 B 通道、中路、A 小道和 A 大道分路，经过视线检查才射击；失去视线后追踪短期记忆位置，随后返回路线。角色会避让并与墙体、箱体、门体碰撞。枪弹受地形和队友遮挡，不造成友军伤害，头部命中提高伤害。

回合内没有复活。队伍被歼灭时结算；时间耗尽时先比较存活人数，再比较剩余生命值总和，完全相同则平局。所有成员下一回合恢复生命、弹药，击杀和阵亡数据保留至整场结束。观战可通过 Space 或「下一位」切换仍存活的队友。

地图占地依据此前项目中的用户提供的 820 × 805 Dust II 鸟瞰图，比例为 0.14 游戏米/像素；高低关系来自已有的 NAV 整理数据。保留实体台阶、CT 下穿、上层小道、主要道路、掩体和门体。美术为简化的低多边形重建，未打包原游戏模型、贴图或音频。

渲染采用原生 WebGL：日间暖色阳光、静态阴影贴图、沙色墙面、程序化表面、实体武器、队伍配色、枪口焰和弹道。音频采用 WebAudio 合成，包含枪声、玩家与 AI 脚步、换弹、刀具开合、挥击、命中与回合提示，按距离衰减并左右定位。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| dust2-layout.js / dust2-architecture.js / dust2-objects.js | 地图占地、高度层、原地图掩体 |
| terrain.js / fps-map.js | 寻路、高低差、碰撞、视线 |
| fps-match.js | 5V5 AI、武器、伤害、回合、检视状态 |
| fps-renderer.js | WebGL 场景、光影、人物与枪械/刀具动画 |
| fps-audio.js | 空间音效与音量 |
| fps-game.js / viewport.js | 操作、HUD、手机横屏 |
| scripts/build-site.cjs | 白名单静态打包 |
| tests/fps.cjs / tests/fps-ui.py | 逻辑、完整 AI 对局、浏览器及触控验证 |

dust2-terrain-data.js 与 scripts/ 下的地图整理工具只用于地图构建，不随网页加载。

## 验证与发布

需要 Node.js 18 或更新版本运行开发检查：

    npm run check
    npm test
    npm run build

浏览器测试另需本机 Chrome 与 Python Playwright：

    python tests/fps-ui.py
    python tests/fps-ui.py http://127.0.0.1:4173/

默认测试 dist/index.html。测试在无界面 Chrome 中禁用操作系统鼠标锁定；检查真实键盘/触点、移动并开火、多种检视、换弹、暂停、观战与结果界面、实际 WebAudio 波形、WebGL 错误及四种移动视口。截图保存在被 Git 忽略的 test-results/。设备模拟不代替真机性能测试。

推送 main 后，GitHub Actions 执行语法检查、逻辑测试和静态打包，再发布 dist/ 至 GitHub Pages。文件使用相对路径，可离线打开，也可部署到网站子目录。见 [发布说明](PUBLISHING.md)。
