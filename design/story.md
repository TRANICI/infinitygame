# 零号病区：别替我签字

本章剧情已接入开场、院区纸条、三张号码牌、三份支线交接单、旧翼档案、离岗广播和结局。下面是统一口径，后续文本按这个写。

## 这次到底出了什么事

林秋以前在这家医院上夜班。妹妹小满住过这里，三年前已经转院，后来回了家。林秋知道医院关了，可凌晨收到一句旧录音剪出来的求救：“哥，我还在医院。来接我。”他还是回来了。

医院的交接系统有个规定：没人接班，就沿用上一班的名字。关院时没人停掉它。林秋的名字被填了三年，院子里也慢慢多出一个觉得自己就是林秋的东西。它会背岗位、口令和巡查路线，却不知道妹妹是谁。

它想让林秋亲手签一次交接单。只要真的林秋认可它接了班，它就能用这个名字出门。电脑不能替它完成这最后一步。

玩家要做的是查清小满已经离院，再用旧门禁的三个印章结束值班、打开出口。**“确认离岗”与“给代班人签字”是两件事。**不做一个选错就突然暴毙的签字按钮；这一章把风险讲清楚，让玩家主动拒绝。

## 四段调查

### 1. 门锁了，先找出路

开场：医院关了三年，广播却让你接班。值班簿上昨天、前天和上个月的签名全是你。

入口给实际路线：分诊牌 → 工具柜 → 候诊庭院排水泵 → 转运维修间 → 消毒连廊。先让玩家有事情做，再让纸条里的不对劲慢慢积累。

门卫便条：“这张是我写的。要是下一张说别开门，你先看字迹。那张不是我。”

工具柜密码依据分诊牌：急诊 3、儿童 1、留观 7，按救治顺序得到 **317**。情绪句不藏密码。

### 2. 小满已经走了

三个旧号码牌用于广播台总电源授权。它们同时给出身份、警告和转院事实：

- 001：你的名字，但你不记得领过这张牌。
- 017：“哥，别签字。签过就出不去了。”
- 217：小满三年前已经转院。

三份支线交接单进一步说明有人冒名：花园下班申诉、广播里的重复点名、药房里的录音提醒。它们可以漏拿，主线仍讲得通。

花园：“我昨晚下班了。钥匙放门卫那儿了。要是还有人看见我，别叫我回去。我真下班了。你们不能天天这样。”

广播：“林秋到岗。林秋离岗。林秋到岗。等会儿，别放了，我还没走出去。谁又把开头按了一遍？”

### 3. 有人想用你的名字

旧翼用正常操作文案引导配电和门禁：A、C 接通，B 断开；密码 **0217**。旁边再放异常句：“B 那路别开。房间已经拆了，呼叫铃还会响。我去看过。没有床。它还在催我换床单。”

病房里的小满记录说，自己只住一天，护士却说她住了几年。观察室记录准确写出玩家正在阅读，让日常记录变成监视。

档案室揭示自动续班设置。最后一页像在求人，又像在发火：

> 我替你上班，你替我签字。不行吗？我都替你这么久了。
> 你的手拿笔就行。名字我会写。

代班者会在这些区域巡查。它背得出交班口令，却回答不了小满是谁；被它抓住会触发短暂突脸，再回到入口，调查记录保留。

### 4. 先出去，别签

三枚印章按小满的三格画排列：**日 → 雨 → 月**。广播台结束值班，打开庭院出口。西侧门闩允许直接返回，避免完成高潮后再重复走迷宫。

打印机最后一张纸：“林秋已离岗。代班人——还是林秋。”

你没签，门开了。手机从 02:17 跳到 02:18。身后的广播说：

> 人已经走了。没走，我还在。下一位呢？

林秋成功离开；名字还留在系统里，作为后续章节的钩子。本章不把妹妹生死留成故弄玄虚的问题：她确实早已离院。

## 说话规则

- 每张纸先说具体人、物、操作。少用“阈限、回响、记忆频段”这类抽象词。
- 疯癫感来自重复、改口、着急争辩，不是每句都打哑谜。普通检修说明保持正常。
- 不把精神疾病当怪物成因。这里是异常岗位与身份冒用，人物是累坏了、吓坏了，讲话才乱。
- 错误操作说明告诉玩家怎么重试，不嘲笑玩家，不扣关键道具。
- 已读纸条可在 J 笔记回看；院区抄录记录在 I 背包里也能看。
