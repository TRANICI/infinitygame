# 代班者 / THE RELIEF · 0.7.0

2026-10-28：重做实机形象。角色约 2.45 米高，保留冒名替班的医院叙事；美术随用户提供的游戏截图统一为低清、灰绿的复古病院风格。

旧版存在三个问题：矩形躯干和细长直臂连接生硬；面部横条像表情符号；面部与工牌在多灯叠加下过曝。新版使用有截面变化的长衣、偏斜肩线、分开的衣摆、短袖口、长前臂和分指手掌。面具只有一条偏斜封口线、封条与浅浅的第二层面部压痕，避免卡通眼睛与嘴巴。三张重复工牌呼应身份冒用。

头部、上臂、前臂、双腿和工牌分别绘制。巡逻时拖步，追逐时步幅增大、前臂前伸；停下搜查时转身扫描。面具随头部轻微偏转，工牌与步伐有相位差。模型共 5,586 个顶点、9 个部件，首次出现时上传，之后复用缓冲区。运行不加载外部模型、图片或网络资源。

`relief-model.js` 中同一个 `WardRelief.mask` 用于实机面具、兼容渲染精灵与被抓近景。近景持续 680 毫秒，不含白屏闪烁；设置可关闭突脸，也可单独减少动态效果。

巡逻 2.25、声源调查 3.3、追逐 5.65 米/秒，玩家步行 4.2、冲刺 6.96 米/秒。开局及被抓恢复后有 12 秒缓冲。丢失视线后追踪最后位置约 7 秒，再搜查 5 秒；躲藏不会暴露新的坐标。声源改变会立即废弃旧路线。被抓保留背包、机关和探索记录。

`tests/pursuit.cjs` 验证追逐、藏匿、声源和搜查；`tests/pursuit-ui.py` 验证实机、突脸与恢复；`tests/polish-ui.py` 检查模型顶点有效性、动画边界、缓冲复用和低动态效果。截图保存在本地 `test-results/relief-v2-*.png`。

早期概念图 `the-relief-concept.png` 仅作历史资料，不随网页发布；它的写实风格不代表当前实机。尚未实现语音台词、模仿玩家动作或复杂手部抓取动画。
