# 伏行者 / THE CRAWLER · 0.8.0

全新四足追逐者。旧模型、旧面部画法、旧概念图和人形动画已从当前版本移除。

伏行者约 1.31 米高，宽背低伏，四肢向外折开；躯壳由连续多边形截面构成。头部在身体前下方，没有眼睛，深色凹陷口部周围有八块不规则浅色硬片。背部、头部、四条腿独立绘制，使用对角足交替推进与抬足；停下时躯壳轻微起伏，头部探动。没有人类服饰、面具、工牌或直立行走形态。

实机源文件为 `stalker-model.js`，六个网格共 4,812 个顶点，首次出现后复用显存。近身效果和兼容精灵采用相同的无眼口部结构。场景延续用户参考图的低清灰绿病院风格。

巡逻 2.25、声源调查 3.3、追逐 5.65 米/秒；开局及被抓恢复有 12 秒缓冲。躲藏不泄露新坐标，抓人需要视线和相同楼层，被抓保留道具与解谜进度。

脚步是落地、二次接触和短促摩擦三层合成。左右声像随玩家朝向改变，距离在 22 米内衰减，遮挡进一步减弱。近距离也保留中频，便于手机扬声器播放。停下不产生脚步；设置提供左右脚步试听。

验证：`tests/pursuit.cjs`、`tests/pursuit-ui.py`、`tests/polish-ui.py`、`tests/audio-ui.py`。浏览器截图保存在本地 `test-results/crawler-*.png`。
