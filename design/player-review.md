# 玩家流程审查 · 0.7.0

本次依据源码、浏览器截图、确定性碰撞行走和实际界面操作审查。它不等同于真人长时间试玩。

| 问题 | 已完成的调整 | 验证 |
| --- | --- | --- |
| 追逐者像拼接方块、面部过曝 | 连续截面长衣、分段肢体、错位封口面具、下调材质反射色 | 正面/侧面/背面截图、动画顶点边界 |
| 被抓近景与角色长相不一致 | 实机与近景共用面具绘制 | 突脸及关闭选项测试 |
| 新声源仍沿旧路线移动 | 声源改变立即清路径并重新寻路 | 追逐逻辑回归 |
| 搜查时呆站 | 保留最后已知位置，不再追踪隐藏坐标，增加原地转身扫描 | 隐藏坐标、搜查朝向测试 |
| 暂停后的手机摇杆未归位 | 清除触点编号、方向、冲刺状态和摇杆偏移，处理失去捕获 | 手机模拟触点恢复测试 |
| 设置滑块获得焦点后 Esc 无效 | Esc 正常关闭设置并回到暂停 | 键盘测试 |
| 缺少低动态选项 | 跟随系统默认，也可保存独立选择；关闭行走晃动和突脸缩放 | 实际相机位置比较、设置恢复 |
| 体力耗尽时反馈不明确 | 显示“恢复中”，补充脚步强度提示 | 浏览器 HUD 检查 |
| 画风与用户参考图不同 | 最高 800 像素场景宽度、像素缩放、灰绿墙面与深绿墙裙、方砖、柔和灯光、圆筒手电、去面板底色 HUD | 室内、庭院、移动端截图 |

地图、背包和笔记仍可随时打开，HUD 仅保留主目标与核心状态；原有支线进度在背包/笔记中查看。所有谜题、房间、捷径和存档兼容逻辑保留。

发布检查包括 `npm run check`、`npm test`、构建后的 `/infinitygame/` 子路径四套浏览器测试。主线界面测试完成号码牌、供电、时间门禁、三枚印章、离岗广播和出口；追逐随机性单独验证。路线测试实际沿碰撞数据行走，界面测试使用定位来隔离谜题逻辑。

后续仍需要真人确认追逐节奏、长时间舒适度和迷宫重复感。早期写实原画、语音台词、动态翻窗和模仿动作未作为本次完成内容。
