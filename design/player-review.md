# 玩家流程审查 · 0.8.0

本次依据源码、浏览器截图、实际音频采样、确定性碰撞行走和界面操作审查。没有将自动化测试等同于真人长时间试玩。

| 问题 | 调整 | 验证 |
| --- | --- | --- |
| 手机需要横屏 | 手机始终使用横屏逻辑尺寸；竖屏时整体旋转，不显示旋转提示 | 390×844、844×390、320×568 的实际按钮触点与画面边界 |
| 旋转后移动和观察可能错轴 | 对摇杆和视角滑动应用逆旋转坐标，尺寸变化清除旧触点 | 前进方向、视角横纵轴、连续旋转、小屏主菜单 |
| 音效听不见 | 交互音效与暂停环境声分开；用户触摸/键盘操作恢复音频；重调增益与中频 | 输出端实际 PCM 采样、零音量、手机中断恢复 |
| 追逐者脚步不明显 | 重做落地、二次接触和摩擦音；左右定位、22 米距离衰减、遮挡衰减 | 左右声道能量与远近音量比较、实际 AI 发声 |
| 需要彻底换掉追逐者 | 删除旧模型与概念图，制作低伏四足的伏行者 | 六个网格的有限顶点、动画边界、正侧背截图 |
| 场景风格需匹配用户截图 | 最高 800 像素渲染宽度、灰绿墙面、墙裙、方砖、柔和灯光、圆筒手电、简洁 HUD | 桌面和手机浏览器截图 |
| 暂停后触控残留、设置 Esc 失效 | 清除触点与摇杆状态；设置输入框接受 Esc | 浏览器回归 |
| 需要减少动态效果 | 系统偏好默认值及独立设置，关闭行走晃动和突脸缩放 | 实际相机位置比较、设置恢复 |

原有房间、路线、谜题、背包、笔记、地图与存档仍保留。构建输出删除已废弃的运行文件，防止旧模型随新版发布。

发布检查：`npm run check`、`npm test`、`npm run build`、`python tests/packaged.py`。六套浏览器测试在 `/infinitygame/` 子路径运行。主线界面测试完成号码牌、供电、时间门禁、三枚印章、离岗广播和出口；路线测试实际沿碰撞数据行走，界面测试用定位隔离机关逻辑。

音频采样可验证程序确实生成非静音信号和声道分布；设备静音、浏览器站点声音权限和实际扬声器效果仍取决于用户设备。
