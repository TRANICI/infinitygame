# 从玩家操作流程审视这次改造

这是基于代码、无界面浏览器观察和实际碰撞行走检查的设计审查，不代表真实用户试玩反馈。

后续更新（2026-10-28）：追逐者已接入，加入近身突脸和紧张反馈；最终采用简单低多边形画风，墙面回退灰黄细颗粒版本。M 地图改为探索记录，未知房间、几何和标记不会提前显示，探索随存档保存。下表保留首轮改造记录。

| 原问题 | 玩家会遇到什么 | 本轮改动 |
| --- | --- | --- |
| 庭院空间大，目标间缺少事情做 | 长时间走路，路边物件像摆设 | 保留原路线，在入口、候诊区、门诊区加入三个谜题，增加屏风和转运床分隔视线 |
| 只在贴近物件时出现 E | 分不清装饰与可操作物 | 4.5 米内、视线范围内给柔和暖光；缺工具为琥珀色，完成后熄灭；遮墙、跨楼层和躲藏时不提示 |
| 交互按中心点算距离 | 宽门边上站很近也按不到 | 使用旋转包围盒表面距离，保留朝向、楼层与视线检查 |
| 大门、窗户、木板只是背景 | 玩家没有改造路线的能力 | 木板可撬；门可换保险芯；后窗可安静拆开或砸开；碰撞、模型、地图与存档同步 |
| 解谜偏找物件、跑腿 | 拿东西没有判断过程 | 分诊顺序柜 317、加权阀门压力 4、处方三项核对；错误输入不扣资源 |
| 新房间容易变成死路 | 搜完只能原路折返 | 茶水间增加后窗，消毒连廊增加可修通的近路；原主线不被支线卡死 |
| 追逐与温馨叙事混在一起 | 玩家不知道要紧张还是放松 | 暗色病院、低频电流声、冒名交接剧情；清掉团子陪伴台词 |
| 线索分散在面板里 | 玩家忘记下一步，重复找纸 | HUD 显示院区下一步，J 汇集已读记录，I 保存工具用途和院区纸条 |

## 新路线与反馈

入口读分诊牌、转出 317 拿撬棍 → 候诊庭院开小阀和大阀（1+3），排水取保险芯 → 维修间拿螺丝刀 → 拆消毒连廊木板 → 更换大门保险芯 → 直接穿到门诊方向。工具保留，保险芯只消耗一次。

门诊交班条给出冷藏、每次两片、每天三次。茶水间补给柜按这三个条件打开，奖励汽水和空瓶；后窗可以用螺丝刀拆或撬棍砸。两种方式目前区别是即时声响，演示没有敌人响应，不能把它当已完成的追逐战术。

这些都是可选调查：主线仍是号码牌供电 → 配电 → 时间门禁 → 三印章 → 离岗广播 → 院区出口。不会因先用掉某件关键材料而堵死主线。

## 验证与后续边界

- `tests/fieldwork.cjs` 从入口沿碰撞路线逐个接近新机关，检查错误答案、重复领奖、材料消耗、穿过修好通道、存档恢复、隔墙微光和宽门交互。
- `tests/horror-ui.py` 用真实界面完成新增谜题与第一章结局，检查追逐者不移动、不渲染、不抓人，概念图不被网页请求。
- 仍需真人试玩确认阅读节奏、迷宫重复感和亮度偏好。旧翼面积较大，后续应根据试玩路线压缩无内容支路。
- 当前无追逐者，不声称追逐平衡或 SAN 系统已完成。窗户是清出可步行通道，没有翻窗动画；木板拆除与卷帘门打开是即时状态切换，没有制作动画。
